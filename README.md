# pc-rpgmaker2003-doc

**RPG Maker 2003** — Steam app 362870, published by KADOKAWA GAMES and
customised for Degica: the licensed English re-release of a Japanese
game-making tool, copied from the owner's own installation and verified against
it on four criteria. The third consecutive object in one product family, after
[`pc-rpgmaker95-doc`](https://github.com/vs-sr-dev/pc-rpgmaker95-doc) (stolen)
and [`pc-rpgmaker2000-doc`](https://github.com/vs-sr-dev/pc-rpgmaker2000-doc)
(bought). **It is the first object in this collection half of whose content is
already published in another repository.**

99.7986 % of this one without a change. What nobody had ever opened was

databases nobody had compared, plus the half of the tree that belongs to
another repository's chapter.

**The headline is a geometry that nothing states.** Three map files carry no
width and no height. Their two layer chunks are 600 bytes each; read as
little-endian `u16` the values reach 10,131, so the cell is two bytes and there
are 300 of them; and the events inside those same files sit at x = 18 and
y = 14, so the map is at least 19 wide and 15 tall. **20 × 15 is the only
factorisation of 300 that survives both bounds**, and it fell out of a layer
length and two coordinates rather than out of a manual.

**And the second headline is a name.** The pre-briefing recorded that `Archeia`
appears in a directory name and nowhere else in the object. It appears twice in
`rpg2003.exe`, inside the editor's About box, as **`Jasmin "Archeia" Toral`**,
under *Translated by* and again under *Localized and Improved by* — beside
`Jie Xin "Cy" Tan` and `David "Cherry" Trapp`, whose four-clause licence sits in
four binaries and whose form classes are in the resource section. The sample
project is signed work.

**The `J` was confirmed for free.** `pc-rpgmaker2000-doc/docs/06` derived, from
durations alone, that a `J` in a MIDI file's internal Shift-JIS name marks a
jingle. Here it is in the file names, and re-derived on this object's own 141
files the split reproduces **exactly** on the ninety-two inherited ones —
seventeen at 4.245–15.634 s against seventy-five at 29.565–174.993 s, disjoint,
on two independent axes that agree on 140 of 141 files. **The one disagreement
is the finding**: `J2003Horn.mid` took the letter into its file name and not
into its sequence name, because the publisher applied the convention and the
new composer did not.

## What this repository does not do

It does not run anything. The object is an editor, a runtime **and a playable
game**, and nothing here was started. Every claim above is a walk, a hash, a
join, a string or an offset — and where a claim is an inference rather than a
closure, it says so on the same line.
